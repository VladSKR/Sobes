# G1 и ZGC: что выбирать

## За две минуты

- **G1** старается сочетать пропускную способность и управляемые паузы: делит кучу на регионы, помечает живые объекты и эвакуирует их из выбранных регионов.
- **ZGC** выполняет большую часть маркировки и перемещения одновременно с приложением ради коротких пауз.
- Выбор делай по реальным GC logs, p99 задержки и нагрузке; размер heap или название бизнеса сами по себе решения не определяют.

## Что делает G1

Сначала определяет достижимость объектов от GC roots. Объекты, пережившие сборку молодых регионов, копируются (эвакуируются) в Survivor/Old; ссылки на них обновляются. Маркировка старой части во многом идёт конкурентно, а mixed collections выбирают регионы, от которых ожидается полезный объём освобождения. Часть работы требует stop-the-world пауз. Цель `-XX:MaxGCPauseTimeMillis` — ориентир для адаптивного алгоритма, **не жёсткая гарантия**.

## Что делает ZGC

ZGC использует барьеры доступа и метаданные ссылок/указателей, чтобы большую часть работы проводить одновременно с приложением. Это снижает продолжительность пауз на больших кучах, но может стоить CPU и пропускной способности. У ZGC тоже есть короткие паузы; фразы «всегда меньше 10 мс», «throughput строго ниже на 15%» и «для heap >32 GB обязательно ZGC» не являются гарантиями.

Для сравнения запускай **одну и ту же** нагрузку, фиксируй JDK и конфигурацию, читай GC logs: частота и длительность пауз, allocation rate, потребление CPU/памяти, p95/p99 сервиса. Если G1 уже укладывается в SLA, смена сборщика без измерений не обоснована.

```bash
java -Xlog:gc* -XX:+UseG1GC -jar app.jar
# Для ZGC проверяй флаги конкретной версии JDK.
java -Xlog:gc* -XX:+UseZGC -jar app.jar
```

В JDK 21 generational ZGC включается флагами `-XX:+UseZGC -XX:+ZGenerational`. В разных версиях JDK доступность и поведение флагов меняются — проверь документацию своей версии перед включением. Цветные указатели/барьеры доступа помогают определять состояние объекта во время конкурентной работы, но это внутренняя реализация, а не обязательный пункт короткого ответа на собеседовании.

**Проверь себя:** почему пауза GC 200 мс может быть проблемой для p99? Запросы, попавшие в паузу, ждут; но вывод о выборе GC делай по измеренному распределению задержек, а не одному числу.
