# Пирамида тестирования

## За две минуты

- Unit проверяет отдельную логику быстро, integration — совместную работу компонентов, end-to-end — пользовательский сценарий целиком.
- Пропорции тестов выбирай по цене и риску; не превращай диаграмму в строгую квоту.

---

## Пирамида тестирования

```
        /\
       /  \
      / E2E\        (мало, дорогие)
     /──────\
    /Integra-\
   /  tion    \     (средне)
  /────────────\
 /  Unit Tests  \   (много, быстрые)
/────────────────\
```

- **Unit** — тестирование изолированного класса/метода (мок зависимости)
- **Integration** — тестирование взаимодействия компонентов (реальная БД, Kafka)
- **E2E** — тестирование полного сценария через UI/API
