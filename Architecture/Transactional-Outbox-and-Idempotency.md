# Идемпотентность, Outbox и границы транзакции

## За две минуты

- Idempotency key позволяет безопасно распознать повтор одной бизнес-операции; уникальность обеспечивается в источнике истины.
- Outbox записывает бизнес-изменение и событие в одной БД-транзакции; доставка события всё ещё может повториться.
- Таймаут внешнего вызова даёт неизвестный исход: новый charge без проверки может списать деньги дважды.

---

В платёжном/заказном API клиент передаёт idempotency key для конкретной бизнес-операции. В БД храни ключ, состояние, параметры/хэш запроса и результат под уникальным ограничением; повтор с тем же ключом и теми же параметрами возвращает прежний результат, повтор с другими параметрами — конфликт. Не рассчитывай на `if (!exists) insert` без unique constraint: два инстанса пройдут проверку одновременно.

**Outbox:** в одной DB-транзакции записать изменение бизнеса и запись события в outbox. После commit отдельный publisher отправляет событие в Kafka и отмечает доставку. Между publish и отметкой возможен повтор, поэтому consumer обрабатывает `eventId` идемпотентно (inbox/unique constraint). Outbox устраняет окно «DB commit прошёл, а publish не состоялся», но не гарантирует ровно одно получение и не включает внешний HTTP-платёж в транзакцию БД.

```text
DB transaction: order=PAID + outbox(EventId)
        commit
publisher → Kafka → consumer(inbox unique EventId)
```

Для retry выбирай **что** повторяется и **где**: при deadlock/serialization conflict повторяй всю транзакцию после rollback в новой транзакции с ограничением попыток и backoff. При сетевом таймауте внешнего платежа исход может быть неизвестен: запроси состояние по ключу операции или используй идемпотентный API провайдера; нельзя слепо отправлять новый charge. Kafka offset commit не равен DB commit, см. [[Messaging/Kafka-Cluster-and-Consumers]].

Это твоя сильная тема на общем уровне; на интервью стоит точнее называть окна отказов, границы транзакций и уникальные ограничения. Примеры перевода/заказа — [[Architecture/Money-Transfer-and-Order-Design]].
