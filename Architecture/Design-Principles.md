# Принципы проектирования

## SOLID

| Принцип | Расшифровка | Суть |
|---|---|---|
| **S** | Single Responsibility | Один класс — одна причина для изменения |
| **O** | Open/Closed | Открыт для расширения, закрыт для изменения |
| **L** | Liskov Substitution | Подтип должен заменять базовый тип без нарушений |
| **I** | Interface Segregation | Много специфичных интерфейсов лучше одного общего |
| **D** | Dependency Inversion | Зависеть от абстракций, не от конкреций |

### YAGNI
**You Aren't Gonna Need It** — не добавляй функциональность "на будущее".
