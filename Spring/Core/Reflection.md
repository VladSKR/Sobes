# Рефлексия в Spring

## За две минуты

- Reflection позволяет прочитать аннотации, поля и методы во время выполнения.
- Spring использует его в некоторых механизмах создания и настройки бинов; AOP-прокси — отдельный механизм перехвата вызовов.

---

### Рефлексия в Spring
Spring использует рефлексию для:
- Создания бинов (newInstance через конструктор)
- Внедрения зависимостей в поля (`@Autowired` поле)
- Чтения аннотаций (`@Component`, `@Transactional`, `@Value`)
- AOP — проксирование методов
- Jackson — сериализация/десериализация полей
