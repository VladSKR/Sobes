# Рефлексия в Spring

### Рефлексия в Spring
Spring использует рефлексию для:
- Создания бинов (newInstance через конструктор)
- Внедрения зависимостей в поля (`@Autowired` поле)
- Чтения аннотаций (`@Component`, `@Transactional`, `@Value`)
- AOP — проксирование методов
- Jackson — сериализация/десериализация полей
