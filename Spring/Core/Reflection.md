# Рефлексия в Spring

## За две минуты

- Reflection позволяет узнать класс объекта, посмотреть его поля/методы/аннотации и работать с ними во время выполнения.
- Spring читает метаданные классов и аннотаций при построении контейнера и может использовать reflection для внедрения зависимостей.
- AOP-прокси — отдельная идея: объект-обёртка перехватывает вызов метода, например для транзакции.

## Пример

```java
class UserService {
    @Autowired private UserRepository repository;
}
```

Во время создания bean Spring находит поле с `@Autowired` и внедряет зависимость. Для определения кандидата контейнер умеет читать метаданные class-файлов, не загружая каждый класс ради поиска; при работе с конкретным экземпляром использует механизмы reflection/метаданных. Позже AOP-прокси может перехватить внешний вызов метода `@Transactional`: это не «рефлексия автоматически открыла транзакцию», а работа interceptor вокруг метода. См. [[Spring/Core/Transactions-and-JPA]] и [[Spring/Boot/Internals]].
